# Local SVD Recommender
A local movie recommendation engine built with Python, Streamlit, and Matrix Factorization (SVD).

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Download the `ml-latest-small.zip` dataset from [GroupLens](https://grouplens.org/datasets/movielens/latest/).
3. Extract `movies.csv` and `ratings.csv` into this directory.
4. Run the app: `streamlit run app.py`
